# 50-unit production plan

Generated by `tools/production_plan.py` from the sliced parts (`docs/print_results.json`). Bed 340 x 320 mm (Bambu Lab H2D / H2S class - the 260-294 mm parts need it), all parts ASA, 0.4 mm nozzle. Small parts are pooled over a batch of 5 engines.

Already optimised: parts nobody sees (valley beam, end plates, base panels) print at 0.28 mm; show surfaces stay at 0.20 mm and the trumpets at 0.12 mm. Deliberately NOT reduced: the base walls (4 mm) and top skin (5 mm) - a stiff, heavy base is what makes the piece feel solid and keeps the stepper's hum from turning the base into a sound box; and the 4-wall / 25 % gyroid minimum on load-bearing parts from the spec. Printing is ~$115 per engine (filament + machine time), under 1 % of the selling price: quality wins every one of these trade-offs.

## 5. Timeline (8 printers, 1-2 people)

| Week | Work |
|---|---|
| 0 | Order purchased parts for 50 + spares (BOM.md). Order machined parts M01-M06 for **2 engines** on quick-turn and request a quote for 50. Print unit #1 (~1-2 days on 8 printers). |
| 1 | Machined parts for unit #1 arrive (quick-turn 5-10 days). Prep, build unit #1 per ASSEMBLY.md. |
| 1-2 | Unit #1: 48 h burn-in, full QC record, owner review of looks and feel. |
| 2 | **GATE 1 - first article approved.** Only now order the 50-unit machined batch (2-3 weeks) and start the production print run. Any change found on unit #1 goes into config.py first, everything is regenerated and re-verified, then unit #2 is built from the new files. |
| 2-8 | Production printing (~41 days), batches of 5. Part prep and board building run alongside. |
| 4-5 | Machined batch arrives. Assembly starts: ~2 engines per working day per builder. |
| 4-9 | Burn-in shelf of 10 turns over every 2 days; QC; packing. |
| 10 | Last units through burn-in, final QC, ship. |

## 6. Risks and how they are handled

| Risk | Mitigation |
|---|---|
| Something about the real build differs from CAD | Gate 1: one complete unit + 48 h burn-in before the batch. |
| Colour mismatch between parts | One filament lot per batch of 5 for all visible parts. |
| Supplier changes a part (motor cable colours, strip, ESP32 board) | Buy each purchased part for all 50 units in one order, from one batch; spares included in the BOM quantities. |
| Printer fails mid-plate | +5 % reprint allowance; long plates started first; every plate checked against PRINT_REPORT.md settings. |
| Machined part out of tolerance | Full first-article inspection of 5 pieces of every machined part from the batch (drawing dimensions), then 1 sample per engine kit (QC section 1); the crush-rib fits tolerate +/-0.05 on the pins anyway. |
| A unit fails burn-in | Diagnose by fault code, fix, repeat the full 48 h; log every failure to spot process patterns. |
