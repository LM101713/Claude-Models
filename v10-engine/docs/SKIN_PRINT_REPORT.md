## What is cut where

All mounting and fit features are cut in Blender at the parameter positions with 128-segment cylinders (crush ribs 24 segments at 0.6 mm radius; the collector saddle 136 segments - see the code comments for why). Nothing is cut after import in CAD. The moving core (crank, rods, pistons, rails, end plates, valley beam, bearings, drive) stays in CAD and is the reference the skin is checked against (`tools/skin_check.py`).
